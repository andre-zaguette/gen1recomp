# Booker's Heaven

welcome to booker's heaven

## Install

Download the latest `.zip` from [Releases](https://github.com/bryanthaboi/bookers_heaven/releases) and install it from the game: **MODS > Import mod .zip**.

Pushes to `main` cut a new release automatically (`bookers_heaven-X.Y.Z.zip`). Bump `manifest.json`'s `version`, put `[release X.Y.Z]` in a commit message, or run the Release workflow by hand.
